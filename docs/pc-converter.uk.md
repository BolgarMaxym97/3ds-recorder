# r3d2video — записи у високоякісне відео на комп'ютері

MP4, який робить сама консоль, розрахований на телефон: маленький (400 × 480) і стиснутий. Краще відео із
запису (`.r3d` з `/3ds/recorder/recordings/` на SD-картці) можна зробити двома шляхами:

| | [Сторінка конвертера](https://bolgarmaxym97.github.io/3ds-recorder/) | r3d2video (ця сторінка) |
|---|---|---|
| Встановлення | нічого: Chrome, Edge чи Safari на комп'ютері | zip для Windows або Python + ffmpeg |
| Розмір | 1×, 2×, 3× (чіткі пікселі) | будь-який цілий множник (за замовчуванням — з пресета) |
| Екрани | як записано, верхній, нижній, поруч | те саме і ще окремий файл для кожного екрана |
| Для чого | поділитися, YouTube (вищий бітрейт), монтаж (кожен кадр ключовий), Discord (до 10 МБ) | YouTube (H.264 CRF 16), DaVinci Resolve (DNxHR HQ), без втрат (FFV1 + FLAC) |
| Натиснуті кнопки | **Кнопки: Показати** | `--inputs` |
| Лише фрагмент | під відео: Початок тут / Кінець тут | `--trim ПОЧАТОК КІНЕЦЬ` |

**Почніть зі сторінки**: перетягніть на неї `.r3d`, виберіть розмір, екрани і для чого відео. Файл не
покидає комп'ютер. r3d2video — коли потрібен DNxHR, файл без втрат або окремий файл для кожного екрана.

## Windows

1. Один раз встановіть ffmpeg: `winget install --id Gyan.FFmpeg -e`
   (або покладіть `ffmpeg.exe` поруч із `r3d2video.exe`).
2. Завантажте [`r3d2video-windows.zip`](https://github.com/BolgarMaxym97/3ds-recorder/releases/latest/download/r3d2video-windows.zip) (додається до кожного релізу від 1.6.0) і розпакуйте
   будь-куди.
3. Перетягніть один чи кілька файлів `.r3d` (або теку) на **r3d2video.exe** і виберіть, для чого відео
   і як розташувати екрани. Відео з'являться поруч із записами.

## macOS / Linux

Потрібні Python 3, компілятор C і ffmpeg. Один раз зберіть `r3dconv` (`bash tests/pcconv/run.sh` збирає
його й перевіряє все), далі:

    python3 tools/r3d2video.py --preset youtube recording.r3d

## Пресети

| Пресет | Файл | Відео | Звук | Розмір (обидва екрани) |
|---|---|---|---|---|
| **youtube** | `.mp4` | H.264, CRF 16 | AAC 192 кбіт/с, 48 кГц | 1200 × 1440 (3×) |
| **resolve** | `.mov` | DNxHR HQ (DaVinci Resolve, і безкоштовна версія) | PCM, 48 кГц | 800 × 960 (2×, вміщається в 1080p) |
| **lossless** | `.mkv` | FFV1 RGB, кожен піксель як записано | FLAC, як записано | 400 × 480 (1×) |

Збільшення — цілим множником методом найближчого сусіда, тож пікселі лишаються чіткими. Воно відбувається
**до** проріджування кольору (4:2:0 / 4:2:2), тому тонкі кольорові лінії й текст не розпливаються: в MP4
4:2:0 без збільшення один колір припадає на кожні 2 × 2 пікселі екрана 3DS. До того ж YouTube дає відео
від 1440p вищий бітрейт.

## Розташування екранів

`both` верхній над нижнім (як записано) · `top` · `bottom` (320 × 240, власний розмір) · `side` поруч ·
`split` окремий файл на кожен екран · `auto` що є в записі (за замовчуванням).

## Параметри

    --preset youtube|resolve|lossless
    --layout auto|both|top|bottom|side|split
    --scale N        цілий множник замість того, що в пресеті
    --fps N          частота кадрів (за замовчуванням як у записі)
    --no-eq          звук так, як його змішав DSP (без зрізу високих, як у динаміка консолі)
    --inputs         показати натиснуті кнопки (записи з 1.6.0): з обома екранами — збоку від
                     нижнього, інакше в куті
    --trim ПОЧАТОК КІНЕЦЬ  лише фрагмент від ПОЧАТОК до КІНЕЦЬ секунд
    --out DIR        куди писати відео
    --ffmpeg PATH    конкретний ffmpeg
