# Glossary: German (de)

Primary sources (Nintendo of Europe, German):
- [3DS-DE] Nintendo 3DS Bedienungsanleitung (2011): https://www.nintendo.com/eu/media/downloads/support_1/nintendo_3ds_14/Nintendo3DS_OperationsManual_DE.pdf
- [N2DSXL-DE] New Nintendo 2DS XL Bedienungsanleitung (New-generation system software): https://www.nintendo.com/eu/media/downloads/support_1/new_nintendo_3ds/NewNintendo2DSXL_OperationsManual_GER.pdf
- [SD-DE] Nintendo support "Verwendung von SD Cards": https://www.nintendo.com/de-ch/Support/Fruhere-Konsolen/Verwendung-von-SD-Cards-826532.html
- [HG-DE] 3DS hacks guide, German translation (partly translated): https://3ds.hacks.guide/de_DE/ (source: github.com/hacks-guide/Guide_3DS, `docs/de_DE`)

## Conventions

- **Address: du on screen.** The printed manuals use *Sie*, but the console's own messages use *du*. The DS-mode error message quoted in [N2DSXL-DE] reads: „Ein Fehler ist aufgetreten. Bitte halte den POWER-Schalter gedrückt, um das System auszuschalten. Weitere Informationen findest du in der Bedienungsanleitung.“ The 2011 [3DS-DE] prints the same message with a mixed "halten Sie … findest du", which looks like a manual-side edit. Use **du** (the console, Nintendo's later German UI and [HG-DE] all use *du*). Write "Drücke", "Halte", "Wähle".
- **Buttons and menu items:** infinitive verbs or nouns: AKZEPTIEREN, KALIBRIEREN, AUSSCHALTEN (POWER menu), FORTSETZEN, BEENDEN, ÄNDERN, ZURÜCKSETZEN, plus OKAY, WEITER, SPÄTER, FERTIG [3DS-DE], [N2DSXL-DE]. Use infinitives for actions ("Speichern", "Herunterladen", "Deinstallieren"). Note: Nintendo DE writes **OKAY**, not "OK".
- **Capitalization:** German noun capitalization, otherwise sentence case. The manuals print labels in CAPITALS for typography only. On screen: "Systemeinstellungen", "Datenverwaltung", "Allgemeine Einstellungen" [HG-DE faq/region-changing]. Nintendo hyphenates compounds with uppercase words: "HOME-Menü", "POWER-Schalter", "System-Update", "SD Card-Steckplatz", "Nintendo 3DS-System" [3DS-DE].
- **Quotes:** „…“ (U+201E … U+201C): „Nintendo 3DS“-Ordner, „Download-Spiel“ [3DS-DE].
- **Punctuation:** no space before `: ; ! ?`. Use the ellipsis `…`. Number and unit with a space: "2,4 GHz", "30 s", decimal comma [3DS-DE specs].
- **Button names:** Nintendo DE says "L-Taste", "R-Taste" (shoulder), "A-Knopf", "X-Knopf", "HOME-Knopf", "POWER-Schalter" [3DS-DE "die L-Taste, R-Taste und den X-Knopf"].

## App terms (as translated)

Final wording in `app/source/lang/de.c` and the phone page (`build/i18n/web-de.js`). Address: **du** everywhere.
Quotes „…“; after a colon a full sentence starts with a capital letter. Decimals with a comma (1,5 s), a space
before % (`%d %%`). A switch named in running text is quoted: *schalte „Rekorder“ in der Übersicht aus*.
Progress states use the short first-person form common in German UIs: *Speichere…, Starte…, Lösche…*.

## Changed in review (2026-11-19)
- Replay 30 s → **Replay 30 s** (das Replay), gallery badge **Replay** — "Wiederholung" read as "repeat" and clashed with "wiederholen".
- Joining recordings → **zusammenfügen** ("Füge Aufnahmen zusammen…"), not "verbinden".
- LED Solid → **Dauerlicht**; skipped frames → **übersprungen**; "in HOME" → **im HOME-Menü**; Free on SD → **Frei auf SD**.
