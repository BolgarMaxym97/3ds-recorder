# Glossary: Simplified Chinese (zh-Hans)

**What exists officially.** Nintendo (through iQue/神游科技) sold the **iQue 3DS XL** (神游3DS XL, SPR-001(CHN)) in
mainland China from 2012. It had a Simplified Chinese system UI and a Simplified Chinese operation manual, which is
still in the Internet Archive. This is the only official Simplified Chinese 3DS source. Nintendo HK's 3DS pages and
manuals are Traditional Chinese for TWN-region hardware ([H]). There is no Simplified Chinese 3DS documentation from
Nintendo itself. Mainland 3DS users today mostly own Japanese, US, European or TW units and talk about them in community
terms. Where the iQue term is clear and still understood (HOME菜单, 休眠模式, 数据管理), this glossary uses it.
Where nothing official exists, it uses the community word.

Sources used (all text-extracted and searched):

- **[Q]** iQue 3DS XL 使用说明书 (SPR-001(CHN)), archived from ique.com:
  https://web.archive.org/web/20140726113239/http://ique.com/3ds/support/iQue3dsxlmanual.pdf
- **[H]** Nintendo HK 3DS support page (Traditional only): https://nintendo.com/hk/3ds/support.html
- **[G]** 3DS Hacks Guide, Simplified Chinese translation (partly translated):
  https://github.com/hacks-guide/Guide_3DS/tree/master/docs/zh_CN

## Conventions

- **Register.** **您** in the manual: [Q] has 您 34 times and 你 3 times (「感谢您购买iQue 3DS XL」, 「适合您环境的设置
  方法」). 你 appears only inside quoted on-screen text («请选择你喜爱的3DS软件»). The community guide [G] uses 你
  throughout. Use **您**, as Nintendo's software does, and keep sentences short. Requests use 请…:
  「请从HOME菜单的主机设置进行触摸屏校准。」
- **Button and menu labels.** Short verbs or nouns, quoted in **“”** in running text. From [Q]: “确定” “开始” “下一步”
  “结束” “继续” “设置” “读取” “现在不设置” “稍后再说” “返回初始状态”.
- **Punctuation.** Full-width ，。、：（）！？, and **“”** quotes (166 “ vs 1 「 in [Q]). Use ／ (full-width slash):
  「开启／关闭」 ([Q]). Use … (U+2026) for ellipsis.
- **Latin text and numbers.** [Q] puts **no space** between Latin words or numbers and Han characters:
  「SD卡」「HOME菜单」「3D屏」「iQue 3DS XL主机」「34页」「5秒」 (SD卡 80x vs SD 卡 3x). Keep this style. [G] uses
  spaces («SD 卡»), but Nintendo's text doesn't.
- **Button names.** [Q] writes 电源键, HOME键. Use `A键`, `L + Y`.

## App terms (as translated)

Final wording in `app/source/lang/zh-Hans.c` and the phone page. Address: **您**, requests with 请…. Controls named
in running text are quoted with “”, settings paths are written `设置→录制器→开机自启` (no spaces around →).
No space between Han and Latin/numbers (`SD卡`, `30秒`, `4GB`); key combinations keep theirs (`L + ↓ + SELECT`).
